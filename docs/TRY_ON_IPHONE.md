## 第 1 步 · 下载包（2 分钟）

1. 打开 https://github.com/fcubeve-alt/3-minite-face-ritual/actions/workflows/try-on-iphone.yml
2. 点最上面那次成功的运行（绿勾）
3. 页面拉到最下面，**Artifacts** 区有 `face3-unsigned-ipa`，点它下载
4. 解压那个 zip，得到 **`face3-unsigned.ipa`**

> 看不到成功的运行？点右边 **Run workflow** 跑一次，等 5–10 分钟。

---

## 第 2 步 · 装 Sideloadly（5 分钟）

Sideloadly 是个免费小工具，作用是**用你的 Apple ID 给这个包签名并装进手机**。

1. 下载：https://sideloadly.io（选 Windows 版）
2. 安装时它会提示需要 **iTunes** 和 **iCloud**：
   - ⚠️ **不要装 Microsoft Store 版本的 iTunes**，会不认。
   - 要装 Apple 官网的桌面版：https://www.apple.com/itunes/download/win64
   - iCloud 同理，装 Apple 官网版
3. 装完重启电脑

> 这三个装完之后，Windows 才能真正和 iPhone 通信。这一步最容易卡住，
> 卡住的原因基本都是"装成了 Microsoft Store 版"。

---

## 第 3 步 · 装进手机（5 分钟）

1. **用数据线把 iPhone 连上电脑**（无线不行）
2. 手机上会弹「信任此电脑吗」→ **信任**，输入锁屏密码
3. 打开 Sideloadly
4. 顶上的 **iDevice** 应该自动认出你的 iPhone
5. 把 `face3-unsigned.ipa` **拖进** Sideloadly 中间那个框
6. **Apple account** 填你的 Apple ID 邮箱
7. 点 **Start**
8. 弹窗要 Apple ID 密码 → 输入
   - 开了双重验证的话，会再要一个**应用专用密码**：
     去 https://account.apple.com → 登录 → 「App 专用密码」→ 生成一个，粘进去
9. 进度条走完，手机主屏上就出现 face3 了

---

## 第 4 步 · 让手机信任它（1 分钟）

第一次打开会提示「不受信任的开发者」，这是正常的：

**iPhone 设置 → 通用 → VPN与设备管理 → 你的 Apple ID → 信任**

然后就能打开了。

## 试的时候重点看这几样

这个 App **从来没在真机上跑过**，所以第一次装上主要是找问题。
下面每一条都对应一段真实代码，出问题就是真 bug：

### 一定要看的

- [ ] **能不能打开**（闪退的话看第 5 步怎么抓日志）
- [ ] 首页点 **START** 是不是**直接进播放器**，中间没有多余的页
- [ ] 播放器上半屏那张**示意脸上有没有画出路线** ——
      ● 起点、虚线路径、白点在动、◎ 终点。
      20 个动作里有 15 个应该画得出，剩下 5 个（呼吸、鼓气、元音、噘嘴、轻拍）
      本来就没有轨迹，只显示提示和计时，那是对的
- [ ] **一进播放器不该弹摄像头权限**。
      只有点了下半屏的「Turn on the mirror」才该弹
- [ ] **不给摄像头权限**，整套 3 分钟能不能正常做完
- [ ] 给了权限之后，下半屏是不是**镜像的**（抬左手，屏幕上也是左边）

### 容易被忽略但会毁体验的

- [ ] **3 分钟不碰屏幕，会不会自动锁屏**（不该锁）
- [ ] 先放着音乐再开 App，**语音提示会不会把音乐掐掉**（应该只是压低）
- [ ] 做到一半**切出去再回来**，是不是停在暂停（应该是，不该自动继续）
- [ ] 做完 Done 页的**分钟数对不对**，回首页月度汇总有没有 +1
- [ ] 中途按 ✕ 退出，**记录还在不在**（应该在，规格说不惩罚中断）

### 不用管的

- **Paywall 是空的** —— 订阅商品还没在 App Store Connect 里配，预期行为
- **MOCK 角标** —— 内容还没过专家审核，故意显示的
- **视频是示意图** —— 素材还没有，这是设计好的回落

## 第 5 步 · 出问题怎么给我

**闪退**：手机 设置 → 隐私与安全性 → 分析与改进 → 分析数据 →
找 `FaceRitual` 开头的那条，点开，全选复制发我。

**功能不对**：录屏 + 说一句"第几步、期望什么、实际什么"。

**Sideloadly 报错**：把错误原文发我。常见的：

| 报错 | 原因 |
| --- | --- |
| `Could not find device` | 数据线/没点信任/装了 Store 版 iTunes |
| `Unable to sign` | Apple ID 密码错，或开了双重验证但没用应用专用密码 |
| `Maximum App ID limit` | 免费账号一周最多 10 个 App ID，等一周或换个 Apple ID |
| 装上但打不开 | 第 4 步的「信任」没做 |

## 7 天后过期了怎么办

免费 Apple ID 签的包 7 天失效，打开会闪退。重做第 3 步就行 ——
**App 里的练习记录不会丢**。

嫌麻烦的话，装 [AltStore](https://altstore.io) 可以自动续签
（要求电脑和手机在同一个 WiFi 下，电脑开着）。
但真要长期用，还是买开发者账号走 TestFlight 更省事。
